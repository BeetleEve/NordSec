# Источники

Оформление использует белый фон, тёплый оранжевый акцент и логотип основного сайта
фонда. Сайт NordSec — отдельный учебный проект; содержимое обращений и демонстрационные
участники не являются данными фонда.

- Основной сайт: https://t-dobra.ru/
- Логотип: https://t-dobra.ru/wp-content/themes/2026/assets/images/logo.svg
- Django: https://docs.djangoproject.com/en/5.2/
- PostgreSQL: https://www.postgresql.org/docs/
- WhiteNoise: https://whitenoise.readthedocs.io/en/stable/django.html
- Waitress: https://docs.pylonsproject.org/projects/waitress/en/stable/runner.html

Локальные SVG-иллюстрации созданы для интерфейса NordSec. Они используются,
когда у вещи нет фотографии, и обозначают категорию, а не фактический внешний вид вещи.
