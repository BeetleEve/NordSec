# NordSec

Карта бесплатных вещей: у владельцев и на улице. Человек может отметить оставленную
вещь и идти дальше; другой участник найдёт её на карте. Для домашних вещей доступна
прямая связь с автором. Модератор проверяет публикации, а не организует передачу.

Python + Django + PostgreSQL, серверные HTML-шаблоны, JavaScript и Leaflet.

## Запуск

Открыть проект в PyCharm → выбрать `.venv/Scripts/python.exe` → запустить `main.py`.
Локальная PostgreSQL запускается на порту 55432; сайт — http://127.0.0.1:8000/.
Для нового устройства с тестовыми данными: `python main.py --demo-db`.
Реквизиты подключения хранятся в локальном `.env` и не включаются в Git.

## Подключение БД PostgreSQL

Запустить проект в PyCharm (`main.py`) → открыть pgAdmin → нажать правой кнопкой
на **Servers** → **Register → Server…** → во вкладке **General** указать
**Name: NordSec** → перейти во вкладку **Connection** и заполнить:

- **Host name/address:** `127.0.0.1`
- **Port:** `55432`
- **Maintenance database:** `nordsec`
- **Username:** `nordsec`
- **Password:** см. личку в ТГ.

Включить **Save password?** → нажать **Save** → раскрыть
**NordSec → Databases → nordsec → Schemas → public → Tables


## Аккаунты

Пароли хранятся как хеши Django PBKDF2-SHA256 с индивидуальной солью.
При входе проверяется пароль, расшифровки старого пароля нет.

Создание доверенного модератора при работающей PostgreSQL:

```powershell
.venv\Scripts\python.exe manage.py create_account moderator-login "Strong-password-2026!" moderator
```

Пароль примера замените своим. Для скрытого ввода:

```powershell
.venv\Scripts\python.exe manage.py create_account moderator-login --role moderator
```

Роли команды: member, volunteer, moderator. Помогать с вещами может любой участник;
роль volunteer не является допуском к карте или к перевозке.
Аккаунт модератора не даёт прав суперпользователя панели `/admin/`.

## Концепт и проверки

- Два типа объявления: home и street.
- Улица: фото и точка обязательны, телефон не нужен, срок — шесть часов.
- У владельца: примерное место на публичной карте, телефон после входа.
- Геолокация с высокой точностью по разрешению браузера; метка передвигается вручную.
- Поиск улицы по кнопке, без фонового автодополнения.
- Автопроверка правил для всех; сомнительные объявления направляются модератору.
- Отметки наличия, сообщения об отсутствии, жалобы, избранное и свои объявления.

Исторические обращения, резервы, выдачи и поручения сохранены для целостности прежних
данных. В новом пользовательском пути они не используются.

```powershell
.venv\Scripts\python.exe main.py --test --no-browser
```

Проверка состояний карты без браузерных разрешений (если установлен Node.js):

```powershell
node scripts/check_map_ui.cjs
```
